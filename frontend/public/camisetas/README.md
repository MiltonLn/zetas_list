# Imágenes de camisetas

Esta carpeta contiene los assets estáticos del pedido de camisetas (`/camisetas`).

- `guia-tallas.png`: guía de tallas mostrada en el formulario.
- `camiseta-local.svg`, `camiseta-visitante.svg`, `pantaloneta.svg`: placeholders de los
  modelos. Reemplázalos por las imágenes reales.

Si subes imágenes con otra extensión (por ejemplo `.png` o `.jpg`), actualiza las rutas
`imageUrl` del catálogo en `backend/src/orders/catalog.ts`.
